# Jay影视 - 完整PHP影视站点系统

一个功能非常完善的PHP影视网站系统，界面精美，响应式适配，管理后台功能强大。

## ✨ 功能亮点

### 🎬 前端功能
- 精美TMDB风格UI界面，紫色渐变主题（可自定义主题颜色）
- 响应式自适应：手机/平板/电脑完美适配
- 首页轮播大图展示、热门推荐、电影、电视剧、动漫、综艺分区
- 详情页：海报、简介、演员、季数选择、普通话/原版语言切换
- 分季分集切换，拉取对应季的详情、简介、年份、评分、演员
- 搜索页、分类页
- 用户系统：邮箱注册（需要验证码）、登录
- **未登录用户禁止播放**，自动跳转到登录页并提示
- 播放页使用 yyzy-tv API + ffzyplay 解析器播放
- 个人中心：收藏、观看历史（精确到秒）、自定义头像上传、修改密码
- 反馈功能：发布反馈、点赞、回复，管理员回复在普通用户回复之上且有"开发者"红色Logo标识
- 超过3条回复自动收起，支持"展开全部"按钮
- 公告系统：首页弹窗，用户勾选"不再提示"后隐藏，新公告再次显示
- 所有图标使用纯CSS/SVG实现

### ⚙️ 管理后台（杰同学 / 101113）
- 仪表盘：用户数、封禁数、收藏、观看时长、最新注册、最新反馈等统计
- 用户管理：搜索筛选、封禁（支持自定义时长）、解封、删除；封禁自动发邮件通知用户（含封禁时间和解封时间）
- 播放源管理：添加、编辑、删除、启用禁用、排序
- **两个独立模块：观看历史管理 + 用户收藏管理**，支持按指定用户筛选
- 反馈管理：管理员回复（高亮"开发者"标识）、标记处理、删除
- 公告管理：新增/编辑/删除；修改或新增会自动重置所有人"不再提示"
- 邮件通知：给指定用户/所有用户自定义内容发邮件（调用SMTP）
- 主题设置：20种预设颜色 + 自定义颜色选择器，实时预览
- 系统参数：网站名称、解析播放器地址、TMDB Key/Token

## 🚀 快速部署

1. 上传所有文件到PHP服务器（支持InfinityFree等所有PHP空间，兼容PHP 5.6 - 8.x）
2. 确保 uploads/ 目录有写入权限（777）
3. 浏览器访问 `install.php` ，填写您的数据库信息后点击安装
4. 安装成功后自动跳转到首页
